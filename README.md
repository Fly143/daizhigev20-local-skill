# 殆知阁古籍库本地检索工具

对 [daizhige-org/daizhigev20](https://github.com/daizhige-org/daizhigev20)
（20587 部典籍、5.2 GB Markdown）做**离线全文检索**的工具集。

- 索引：`index.tsv`（2.8 MB，6 列：路径 / 书名 / 分类 / 作者 / 字节数 / 外部链接）
- 变体表：`variants.tsv`（1053 组，由 `build_variants.py` 从书名简繁对自动生成）
- **本仓库不含古籍正文**，数据需从上游获取（见下）

## 获取数据

```sh
git clone -b data --depth 1 https://github.com/daizhige-org/daizhigev20.git
```

默认读取与工具同级的 `daizhigev20/` 目录，也可用环境变量指定：

```sh
export DZG_DATA=/path/to/daizhigev20
```

查找顺序：`$DZG_DATA` → 同级目录 → `/workspace/daizhigev20` → `~/daizhigev20`

## 命令

```sh
gj find    老子                    # 找书
gj grep    天地不仁                 # 全库检索（8 核并行）
gj grep    仁 --in 老子             # 限定书名（自动展开同书异名）
gj grep    仁 --in =道德真经         # = 表示精确书名
gj grep    刍狗 --in 老子,庄子       # 多本 OR
gj grep    圣人 --in 简帛 --loan     # 帛书借字（声人）
gj chapter 道德真经 --list          # 列章节
gj chapter 道德真经 虚用章          # 读某一章
gj show    道藏/藏外/王弼老子注.md 30 40
gj meta    道德真经                 # 元数据 + 外部链接
gj links   --prov ctext            # 外部参照表
gj dup     --hash                  # 查重
gj stats
```

grep 选项：`--in 书名[，书名]` `--ctx 40` `--limit 30` `--per 3` `--jobs 8`
`--variants/--no-variants` `--loan` `--all` `--files` `--json`

## 准确率相关的设计（重点）

### 1. 变体字匹配：数据驱动，而非手写

从 **16319 组简繁书名对**逐字对齐提取，得到 1053 组变体（`variants.tsv`）。

关键处理：**剔除「一简对多繁」**。简体「复」同时对应「復」(返回) 和「覆」(覆盖)，
若合并则搜「复」会误中所有「覆盖」（该字占 12.6%）。同理隔离 `曆/歷`、`鬍/胡`、
`鐘/锺`、`彙/匯`、`讚/贊`、`鍊/煉`、`甯/宁`、`衚/胡`、`著/着`，共 11 字。

> 抽样实测：`羣/群` 异体占比 74.5%、`槩/概` 50.4%、`徧/遍` 31.6%——
> 这些是**同一字的不同写法**，合并是对的，召回率提升巨大。

### 2. 同书异名展开（`ALIASES`）

`--in 老子` 会自动展开为「老子 / 道德经 / 道德真经 / 五千文 / 道德经古本篇」。

> 修复前 `--in 老子` 命中 25 本注本，却**漏掉《道德真经》正文**（书名无「老子」二字）。
> 现已覆盖 36 组常见异名（庄子/南华经、列子/冲虚真经、周易/易经…）。

### 3. 精确书名匹配

`--in =道德真经` 只命中那一个文件；不加 `=` 是子串匹配（会命中 70+ 本注本）。

### 4. 超长行保护

全库 1.97% 的行超过 500 字（最长 80741 字）。输出时超过 400 字自动截断，
避免一次刷屏几千字。

## 性能（实测，5.2 GB / 20587 文件）

| 操作 | 耗时 |
|---|---|
| `find` / `meta` / `show` / `chapter` | 0.1–0.2 秒 |
| `grep --in 书名` | 0.2 秒 |
| `grep` 全库（8 核并行） | **3.3 秒** |
| `grep` 全库（串行基线） | 10.6 秒 |

## 已知限制

| 限制 | 实情 |
|---|---|
| 无语义检索 | 只能字面/变体匹配，「讲无为的段落」这种意图理解不了 |
| `author` 缺失 11889 部 | 仅 217 部能从书名括号补出，其余数据源本身没有 |
| 变体表非完整繁简表 | 1053 组来自书名用字，正文生僻异体仍可能漏 |
| `--loan` 仅老子类成立 | 47 组借字，用在其他典籍会误伤，默认关闭 |
| 多词默认要求彼此靠近 | 两词相距超过 30 字视为巧合，自动过滤（`--near N` 可调，`--near 0` 关闭） |
| 全库 3.3 秒 | 5.2 GB 顺序读的物理下限（1.6 GB/s） |

## 数据问题（已核验）

| 问题 | 实情 |
|---|---|
| 无 frontmatter | 仅 2 个：`FONTS.md`、`README.md` |
| 最长 frontmatter | 2247 字节，读取上限设 8192 |
| 跨藏重复 | 1492 组同名书；`dup --hash` 可比内容 |
| 目录页 | 如 `册府元龟.md` 是 75 KB 目录，正文在 1003 个分卷文件 |
